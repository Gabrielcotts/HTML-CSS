Explicação de tags

A tag <h1> é feita para título. Existem outras variações dessa tag. As tags de titulos vão do <h1> ao <h6>.

A tag <p> em HTML é feita para criar parágrafos.

A tag <hr> é feita para cria uma linha horizontal que representa uma separação temática no conteúdo. Essa tag tem um padrão diferente, onde só tem a abertura e não possui fechamento.

A tag <br> é feita para quebra de linhas. Ela pode ser usada dentro de outras tags de texto, e por ventura também tem o padrão de uma tag só com a abertura e sem possuir fechamento.
