Estrutura condicional IF-ELSE

Uma variável pode ser declarada assim: int idade = 21;


    int idade = 21;

    if (idade >= 18) {
        System.out.println("Maior de idade!");
    } else {
        System.out.println("Menor de idade!");
    }
IF-ELSE é uma estrutura condicional usada para verificar determinadas regras que você quer determinar no código, funcina quase como uma verificação de informações. Sua estrutura funcina com parênteses () após o IF, onde você instânciará as informações que deseja verificar e pós os parênteses, tem as chaves que fecham o bloco do IF. Caso o IF venha a falhar, usamos o ELSE que por sua vez não tem parênteses, apenas as chaves {}.

Você pode traduzir o IF =

Se
e o ELSE
Se não ou Caso contrário.

SE a condição do IF for verdadeira e retornar true, o IF será é executado e o ELSE ignorado. CASO CONTRÁRIO, o bloco ELSE será executado.
